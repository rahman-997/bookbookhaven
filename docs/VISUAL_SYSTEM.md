# BookHaven visual system

BookHaven uses an editorial, book-first interface rather than generic stock photography.

## Edition covers

- Seeded demo titles use normalized ISBN-13 metadata and no stock-photo cover URLs.
- `BookCover` generates a deterministic BookHaven edition from the title, slug, author and primary category when no external cover URL is supplied.
- Eight deterministic palettes provide visual variety without adding image dependencies.
- Administrators can still provide an HTTPS `coverUrl` for a real publisher cover when appropriate; otherwise the generated edition remains the safe fallback.

## Social imagery

- The homepage exposes a generated 1200×630 Open Graph image.
- Every book route generates its own 1200×630 Open Graph image from live catalog metadata.
- The application icon is generated by Next.js metadata routes.

## Regression guarantees

The free-hosting runtime smoke test verifies that seeded catalog pages do not leak the legacy Unsplash stock images, seeded books expose ISBN-13 values, book pages retain BookHaven edition identity, and the generated Open Graph image resolves to a real PNG response. The same smoke run also exercises registration, session propagation, cart, checkout, orders and exactly-once inventory decrement.
